Gmail MCP

Gmail MCP is a personal tool that lets the Claude desktop app work with the owner's own Gmail accounts: searching and reading messages, applying labels, archiving, and drafting or sending replies.

It runs entirely on the owner's own computer. It is not offered to the public, has no other users, and does not run on any external server.

See the privacy policy for details of how Google user data is handled.
