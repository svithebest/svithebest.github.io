Privacy Policy – Gmail MCP

Last updated: 17 November 2026

Who uses this app

Gmail MCP is a personal tool used only by its owner to access the owner's own Gmail accounts. It is not distributed to, or used by, anyone else.

What data it accesses

With the owner's consent, the app uses the Gmail API to read message content and metadata, manage labels, archive messages, and create drafts or send messages from the owner's accounts.

How the data is used

Data is used only to carry out actions the owner requests through the Claude desktop app on the owner's own computer, such as finding, summarising or replying to email. Message content returned by the Gmail API is passed to Claude (Anthropic) only to fulfil those requests.

Storage

OAuth access and refresh tokens are stored only on the owner's computer, in a local file readable only by the owner's user account. No email content is stored by the app. There is no server, database or analytics service operated by this app.

Sharing

Google user data is not sold, not used for advertising, and not shared with anyone except as described above.

Google API Services User Data Policy

Gmail MCP's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Revoking access makes the stored tokens unusable.
